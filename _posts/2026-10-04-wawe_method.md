> **Поле напряжений → траектории → резонаторы → узлы → сценарии → верификация → социальная способность к небывалому.**

# ЧАСТЬ I. ЯДРО

## 1. Три сущности: траектория, резонатор, узел

Вся работа метода сводится к трём сущностям. Всё остальное — производное.

### 1.1. Траектория

**Траектория** — длящийся процесс, обладающий тремя параметрами и не сводимый к другим траекториям.

| Параметр      | Определение             | Способ измерения              | Пример                               |
| ------------- | ----------------------- | ----------------------------- | ------------------------------------ |
| **Амплитуда** | Сила воздействия        | Объём, число, масштаб         | Объём бюджета, число вовлечённых     |
| **Частота**   | Периодичность импульсов | Интервал между пиками         | Циклы переписи, выборов, проверок    |
| **Фаза**      | Синхронизация с потоком | Кто в фазе, кто в противофазе | Привязка назначений к инвентаризации |

**Типы траекторий:**

| Тип                 | Природа                         | Пример                                           |
| ------------------- | ------------------------------- | ------------------------------------------------ |
| Экономическая       | Распределение ресурсов          | Бюджетный цикл, цикл накопления капитала         |
| Правовая            | Изменение юридических режимов   | Рост судебных исков, смена режимов собственности |
| Антропологическая   | Кадровые и поколенческие сдвиги | Кадровая ротация, демографический цикл           |
| Нормативная         | Сдвиг общественных норм         | Отношение к частной собственности                |
| Техно-экономическая | Инфраструктурные проекты        | Дороги, логистика, трассы                        |
| Финансовая          | Кредитные циклы                 | Внешние заимствования                            |
| Политико-правовая   | Неисполненные обещания          | Акты 1993, 1998 годов                            |
| Биосоциальная       | Смена поколений                 | Демографические волны                            |

**Принцип несводимости:** траектории разной природы не сводятся друг к другу. Экономическое не сводится к правовому, антропологическое — к экономическому. Именно несводимость делает интерференцию источником события.

**Принцип отдельного колебания:** по отдельности траектории дают лишь «колебание». Смысл рождается только при наложении.

### 1.2. Резонатор

**Резонатор** — действующий социальный механизм, который удерживает колебание, отбирает реализуемую возможность и превращает разность потенциалов в событие. Резонатор не является ни траекторией, ни узлом, ни событием. Он — условие возможности события.

| Тип резонатора     | Определение                                  | Пример                           |
| ------------------ | -------------------------------------------- | -------------------------------- |
| Институт           | Устойчивая структура, удерживающая колебания | Государство, церковь             |
| Правило            | Нормативная структура                        | Закон о собственности, регламент |
| Организация        | Кадровая структура                           | Суд, министерство                |
| Фиктивный объект   | Носитель без физического референта           | Ваучер, виртуальная доля         |
| Активный резонатор | Резонатор с самонастройкой                   | Монархия, церковь                |

| Параметр        | Определение                            | Способ измерения                               | Пример                                |
| --------------- | -------------------------------------- | ---------------------------------------------- | ------------------------------------- |
| **Частота**     | На что настроен резонатор              | Периодичность процедур, ритуалов               | Частота заседаний, цикл переписи      |
| **Добротность** | Способность удерживать колебание       | Устойчивость формы при изменчивости содержания | Сохранение процедуры при смене кадров |
| **Полоса**      | Широта спектра резонирующих траекторий | Число траекторий, с которыми резонирует        | Монархия — широкополосный резонатор   |

**Принцип несводимости резонатора:** резонатор не сводится к траектории. Траектория колеблется — резонатор удерживает. Траектория имеет амплитуду, частоту, фазу — резонатор имеет добротность и полосу. Траектория длится — резонатор структурирует.

**Принцип двойного резонатора:** институт существует в двух режимах — как правило (нормативная частота) и как организация (кадровая частота). Институт может быть рассогласован сам с собой: юридическая форма резонирует с одной траекторией, кадровая практика — с другой. Именно это рассогласование создаёт напряжённость.

**Принцип активного резонатора:** резонатор, способный менять частоту для входа в резонанс с траекторией. Критерии: широкополосность, переменная добротность, механизм самонастройки (ритуал, культура, церемония).

### 1.3. Узел

**Узел** — точка пересечения траекторий. Пересечение фиксирует, что сошлось; резонатор фиксирует, что из сошедшегося реализуется. Узел — это пересечение, взятое вместе с резонатором, через который оно становится событием.

**Формат записи узла:**

(t, A₁, A₂, Δφ, R, статус)


где:

- `t` — время узла;
- `A₁`, `A₂` — амплитуды траекторий;
- `Δφ` — сдвиг фаз;
- `R` — резонатор;
- статус — фоновый, событийный, критический.

**Критерий значимости узла:**

| Условие                                                     | Статус узла |
| ----------------------------------------------------------- | ----------- |
| Изменение поведения хотя бы одной траектории в окне ±6 мес. | Событийный  |
| Изменение поведения обеих траекторий                        | Критический |
| Нет изменения поведения                                     | Фоновый     |

**Критерий событийности с учётом резонатора:**

| Условие                                   | Статус узла |
| ----------------------------------------- | ----------- |
| Есть резонатор, настроенный на траектории | Событийный  |
| Есть резонатор, рассогласованный          | Критический |
| Нет резонатора                            | Фоновый     |

**Принцип разной природы:** для наложения выбираются траектории разной природы. Запрещено накладывать траектории одной природы — такое наложение даёт иллюстрацию, а не событие.

## 2. Три тезиса

Метод опирается на три положения. Они не доказываются — они принимаются как рамка.

**Тезис 1. Реальность — поле напряжений.**
Не иерархия сущностей и не совокупность объектов. Поле, в котором сосуществуют автономные колебательные процессы разной природы. Поле не имеет центра, но имеет узлы.

**Тезис 2. Событие — эффект наложения, а не следствие причины.**
Событие возникает в точке пересечения траекторий. Вопрос «почему это случилось?» сменяется вопросом «как это должно было случиться в точке пересечения волн».

**Тезис 3. Резонатор отбирает реализуемую возможность.**
Из спектра возможностей, заложенных в пересечении траекторий, реализуется не «всё, что возможно», а то, что резонатор способен удержать. Резонатор — индикатор реализуемости.

## 3. Запреты

## 

Метод определяется не только тем, что он утверждает, но и тем, что он запрещает. Запреты — не моральные предписания и не идеологические барьеры. Это защита от редукции: от сведения сложного к простому, многомерного к одномерному, поля — к одной из его проекций.

**Запрет монизма.**
Запрещено утверждать, что всё определяется одной субстанцией — экономикой, политикой, культурой, технологией, географией или «волей элит». Монизм удобен: он даёт простую картину и готовый ответ на любой вопрос. Но он избыточен. Если бы все траектории были проекциями одной сущности, интерференция была бы не нужна — событие можно было бы вывести из неё одной.

**Запрет телеологии.**
Запрещено представлять процесс как движение к заранее заданной цели. Ни история, ни общество, ни отдельная траектория не имеют предзаданного финала. Событие — не шаг к цели, а эффект наложения. Метод читает конфигурацию, а не маршрут.

**Запрет субстанциализма.**
Запрещён поиск скрытой сущности за явлениями, которую надо «разоблачить». Видимый мир — не маска, за которой прячется истина. Он — след, по которому восстанавливается породившая его интерференция. Читать след — не то же самое, что искать сущность.

**Запрет иллюзионизма.**
Запрещено трактовать видимый мир как обман, который нужно преодолеть. Плотность фактов, документов, цен — это кристаллизованное напряжение. Мы не разоблачаем видимый мир, но читаем его как след.

**Запрет редукции резонатора к траектории.**
Запрещено трактовать резонатор как траекторию. Траектория колеблется — резонатор удерживает. Траектория имеет амплитуду, частоту и фазу — резонатор имеет частоту, добротность и полосу. Редукция резонатора к траектории уничтожает само понятие условия: событие начинают выводить из траектории, минуя резонатор.

**Запрет редукции способности к возможности.**
Запрещено трактовать социальную способность как реализацию наличных возможностей. Возможность предзадана пересечением траекторий — способность не имеет объекта заранее. Возможность реализуется через отбор; способность реализуется через порождение. Смешение ведёт к тому, что систему начинают оценивать по тому, достигла ли она заявленных целей, — и не замечают того, что она породила помимо них. Система, «не достигшая цели», может обладать высшей способностью — способностью рождать небывалое. Редукция способности к возможности уничтожает само понятие новизны.

Шесть запретов защищают шесть разных входов в редукцию. Монизм сводит поле к одной траектории. Телеология сводит конфигурацию к маршруту. Субстанциализм сводит след к сущности. Иллюзионизм сводит плоть к обману. Редукция резонатора сводит условие к процессу. Редукция способности к возможности сводит порождение к отбору. Каждый запрет закрывает один короткий путь. Вместе они удерживают метод в его собственной оптике: поле, наложение, резонанс, событие, способность к небывалому.

## 4. Шесть различений

Метод теряет различающую силу, если смешивать категории. Запреты защищают от редукции — различения удерживают точность.

### 4.1. Событие и идея

| Событие                          | Идея                                   |
| -------------------------------- | -------------------------------------- |
| След первого порядка             | След второго порядка                   |
| Прямой отпечаток напряжения      | Отклик на напряжение, ставший языком   |
| Плоть напряжения                 | Язык напряжения                        |
| Дано в ощущениях здесь и сейчас  | Дано в языке, в понятии, в учении      |
| Имеет дату, место, участников    | Имеет форму, но не имеет даты          |
| Читается изолированно, но мёртво | Читается только в связке с напряжением |

Событие — плоть напряжения. Идея — его язык. Идея не производит событие. Она артикулирует напряжение, которое уже звучит.

### 4.2. Интерференционный узел и производное учение

| Интерференционный узел                         | Производное учение                |
| ---------------------------------------------- | --------------------------------- |
| Возникает на стыке разнородных траекторий      | Возникает внутри одной традиции   |
| Имеет разность потенциалов                     | Имеет инерцию                     |
| Произносит то, что до него не было произносимо | Пересказывает уже произнесённое   |
| Напряжение ищет язык                           | Язык ищет применение              |
| Резонатор настраивается под идею               | Идея подстраивается под резонатор |

Не всякое учение — интерференционный узел. Первичная идея возникает на стыке траекторий, которые до этого не пересекались. Вторичная — варьирует внутри одной традиции.

### 4.3. Первичная идея и вторичная идея

| Первичная идея                                        | Вторичная идея                     |
| ----------------------------------------------------- | ---------------------------------- |
| Разность потенциалов — измеримое рассогласование      | Инерция — пересказ                 |
| Форма и функция противоречат                          | Форма и функция согласованы        |
| Обещание и возможность расходятся                     | Обещание и возможность совпадают   |
| Наличный язык не вмещает то, что требует произнесения | Язык вмещает всё, что произносится |
| Резонатор настраивается под идею                      | Идея подстраивается под резонатор  |

Разность потенциалов — не метафора, а измеримое рассогласование между формой и функцией, обещанием и возможностью, наличным языком и тем, что требует произнесения.

### 4.4. Траектория и её след

| Траектория                      | Её след                          |
| ------------------------------- | -------------------------------- |
| Длящийся процесс                | Событийная фиксация              |
| Имеет амплитуду, частоту, фазу  | Имеет дату, место, участников    |
| Не дана органам чувств напрямую | Дана в ощущениях здесь и сейчас  |
| Читается через наложение        | Читается изолированно, но мёртво |

Траектория не наблюдаема напрямую. Наблюдаем её след — событие, документ, цифра. Но след не содержит траектории. Он — её отпечаток.

### 4.5. Траектория и резонатор

| Траектория                     | Резонатор                          |
| ------------------------------ | ---------------------------------- |
| Колеблется                     | Удерживает                         |
| Имеет амплитуду, частоту, фазу | Имеет частоту, добротность, полосу |
| Длится                         | Структурирует длительность         |
| Читается через наложение       | Читается через резонанс            |
| Дана в ряду                    | Дана в устойчивости формы          |

Траектория — то, что колеблется. Резонатор — то, что удерживает. Смешение ведёт к тому, что событие начинают выводить из траектории, минуя условие его возможности.

### 4.6. Возможность и способность к небывалому

| Возможность                                   | Способность к небывалому                        |
| --------------------------------------------- | ----------------------------------------------- |
| Реализуется через отбор                       | Реализуется через порождение                    |
| Предзадана пересечением траекторий            | Не имеет объекта заранее                        |
| Резонатор отбирает из наличного спектра       | Система выходит за пределы спектра              |
| Отвечает на вопрос «что сработает»            | Отвечает на вопрос «что родится»                |
| Измерима через реализуемость                  | Измерима по плодам                              |
| Характеризует узел                            | Характеризует поле после события                |

Возможность — то, что уже содержится в пересечении траекторий; резонатор лишь отбирает её. Способность к небывалому — то, чего в пересечении не было; система порождает её. Смешение ведёт к тому, что систему оценивают по реализации наличного — и не видят того, что она породила вопреки спектру.

Шесть различений удерживают метод от шести смешений. Событие не сводится к идее. Узел не сводится к учению. Первичное не сводится к вторичному. Траектория не сводится к следу. Резонатор не сводится к траектории. Возможность не сводится к способности. Каждое различение — это линия, за которой начинается редукция.

# ЧАСТЬ II. ЦИКЛ

Цикл метода — процедуры, следующие одна за другой. Цикл замкнут: событие, ставшее фактом, входит в видимый мир и становится новой траекторией. И оно оставляет после себя социальную способность к небывалому, которая также входит в поле.

## 5. Обнаружение

**Назначение:** выделение траекторий и резонаторов из поля напряжений и внесение их в реестр.

### 5.1. Процедура обнаружения траекторий

**Шаг 1. Выбор объекта.**
Определить объект анализа: земля, деньги, кадры, нормы, тела, поколения.

**Шаг 2. Построение временного ряда.**
Для каждого объекта — построение ряда на горизонте ≥ 5 лет.

**Шаг 3. Фиксация параметров.**
Для каждого ряда — фиксация амплитуды, частоты, фазы.

**Шаг 4. Проверка на несводимость.**
Убедиться, что ряд не сводится к ряду другой траектории.

**Шаг 5. Внесение в реестр.**

### 5.2. Инструменты обнаружения траекторий

| Инструмент               | Источник             | Что даёт                                 |
| ------------------------ | -------------------- | ---------------------------------------- |
| Архивы нормативных актов | Правовые базы        | Частота и фаза правовых режимов          |
| Бюджетные ряды           | Финансовые отчёты    | Амплитуда и частота экономических циклов |
| Демографические таблицы  | Переписи, статистика | Частота и фаза поколенческих сдвигов     |
| Судебная статистика      | Реестры дел          | Амплитуда и фаза правовых волн           |
| Кадровые реестры         | Назначения, отставки | Фаза антропологических сдвигов           |
| Реестры «зависших» актов | Архивы               | Слои неисполненных обещаний              |

### 5.3. Критерий проверки траектории

Траектория считается выделенной, если:

1. её ряд устойчив на горизонте ≥ 5 лет;
2. её параметры (амплитуда, частота, фаза) измеримы;
3. она не сводится к ряду другой траектории.

### 5.4. Процедура обнаружения резонаторов

**Шаг 1. Выбор объекта.**
Определить объект: институт, правило, фиктивный объект.

**Шаг 2. Построение ряда проявлений.**
Построить ряд проявлений объекта на горизонте ≥ 5 лет.

**Шаг 3. Фиксация частоты.**
Определить, на какую частоту настроен резонатор.

**Шаг 4. Фиксация добротности.**
Определить, удерживает ли объект колебание.

**Шаг 5. Фиксация полосы.**
Определить, с какими траекториями объект резонирует.

**Шаг 6. Проверка на несводимость.**
Убедиться, что резонатор не сводится к траектории.

**Шаг 7. Внесение в реестр.**

### 5.5. Критерий достоверности резонатора

Резонатор считается выделенным, если:

1. имеет собственную частоту;
2. обладает добротностью;
3. может быть рассогласован сам с собой;
4. не сводится к ряду траектории.

### 5.6. Пример обнаружения

**Объект:** земельные доли.

**Ряд:** данные переписей сельхозугодий 1990–2020.

**Амплитуда:** число долей без наследников.

**Частота:** 5–7 лет (циклы переписи).

**Фаза:** совпадает с кадровой ротацией в Минсельхозе.

**Несводимость:** не сводится к бюджетному циклу — имеет собственную частоту.

**Результат:** траектория внесена в реестр.

Интерференция демаскирует причинно-следственные петли, нечитаемые в линейной логике. Вопрос «почему это случилось?» сменяется вопросом «как это должно было случиться в точке пересечения волн».

### 6.3. Принцип резонансного усиления

Резонатор не просто пропускает колебание — он его усиливает. Чем выше добротность резонатора, тем сильнее событие.

Сила события = Амплитуда × Добротность резонатора


Если добротность падает — событие гаснет. Если добротность растёт — событие усиливается.

**Шаг 6. Указание условия-триггера.**

**Шаг 7. Оценка вероятности.**

> «Если A сохранит фазу, а B войдёт в пик через T, и резонатор R сохранит добротность, то в точке X с вероятностью p система инициирует действие C».

**Шаг 1.** Определить критический узел.

**Шаг 2.** Определить резонатор, через который проходит узел.

**Шаг 3.** Построить три сценария: базовый, оптимистический, пессимистический.

### 7.5. Правило приоритета

При противоречии между сценариями:

1. **Узел важнее траектории.** Сценарий, построенный на событийном узле, приоритетнее сценария, построенного на изолированной траектории.
2. **Фаза важнее амплитуды.** Сценарий, учитывающий сдвиг фаз, приоритетнее сценария, учитывающего только амплитуду.
3. **Разность потенциалов важнее инерции.** Сценарий, построенный на рассогласовании формы и функции, приоритетнее сценария, построенного на пересказе.
4. **Резонатор важнее траектории.** Сценарий, учитывающий добротность резонатора, приоритетнее сценария, учитывающего только траектории.

## 8. Дискретизация и сборка

**Назначение:** преобразование ситуации через работу с резонатором.

Траектории создают напряжение. Резонатор удерживает его. Событие происходит не тогда, когда созревает напряжение, а тогда, когда резонатор перестаёт его удерживать. Пока резонатор работает, узел остаётся узлом. Как только резонатор теряет способность удерживать, узел срабатывает как событие.

Отсюда следует: преобразование — это работа с резонатором. Не с траекториями, которые автономны и длятся, и не с узлами, которые производны. Резонатор — единственный элемент, который поддаётся внешнему воздействию и при этом определяет исход.

### 8.1. Дискретизация

**Дискретизация** — расщепление целостной структуры на элементы, теряющие резонансную связь. Резонатор разрывается на части, каждая из которых сохраняет форму, но теряет способность удерживать всё напряжение. Широкая полоса становится множеством узких. Высокая добротность распадается на низкие. Самонастройка нарушается: когда дискредитированный резонатор не собирается сам, элементы остаются, связи между ними исчезают. Узел, который удерживался годами, срабатывает как событие.

### 8.2. Сборка

**Сборка** — связывание элементов в целостную структуру, обретающую резонансную связь. Множество узкополосных элементов превращается в единый резонатор. Узкие полосы складываются в широкую. Низкая добротность сменяется высокой. Самонастройка восстанавливается. Собранный резонатор способен удерживать напряжение сразу от нескольких траекторий, и узел, который без него сработал бы как событие, остаётся узлом.

### 8.3. Симметрия двух операций

| Атомизация (дезинтеграция) | Сборка                          |
| -------------------------- | ------------------------------- |
| Разрывает связи            | Создаёт связи                   |
| Понижает добротность       | Повышает добротность            |
| Сужает полосу              | Расширяет полосу                |
| Превращает узел в событие  | Удерживает узел от срабатывания |
| Разрушает резонатор        | Создаёт резонатор               |

Это не два разных действия, а два направления одного процесса: изменения резонансных свойств структуры.

### 8.4. Практическое правило

1. Определи резонатор, через который проходит узел.
2. Реши, что нужно — дискретизировать его или собрать.
3. Только после этого намечай действие.

Направлять преобразование на траектории бессмысленно — они автономны. Направлять его на узел невозможно — он производен. Остаётся резонатор.

> *Траектории создают напряжение. Резонатор удерживает его. Дискретизация разрывает связи — и узел срабатывает. Сборка связывает элементы — и узел удерживается. Преобразование — это выбор между дискретизацией и сборкой.*

## 10. Верификация и социальная способность к небывалому

**Назначение:** проверка сценария и оценка того, что осталось после срабатывания события. Верификация замыкает цикл: событие, ставшее фактом, входит в видимый мир и становится новой траекторией. И оно оставляет после себя социальную способность к небывалому.

Верификация отвечает на три вопроса:

1. **Подтвердился ли сценарий?** Совпали ли зафиксированные узлы с фактическими событиями?
2. **Что осталось после события?** Сохранился ли эффект без формальной поддержки резонатора?
3. **Что стало способно случиться?** Какое небывалое породило событие — и сохранило ли оно жизненную силу?

### 10.1. Процедура верификации

**Шаг 1. Сопоставление узлов.**
Сравнить карту узлов с фактическим ходом событий. Зафиксировать: какие узлы сработали, какие не сработали, какие сработали в иной форме.

**Шаг 2. Проверка резонатора.**
Определить, через какой резонатор прошло событие фактически. Совпал ли он с прогнозируемым.

**Шаг 3. Оценка сценария.**
Определить, какой из трёх сценариев коридора реализовался. Сработало ли условие-триггер.

**Шаг 4. Оценка остатка.**
Определить, что сохранилось после срабатывания узла: удержался ли эффект без формальной поддержки резонатора.

**Шаг 5. Оценка социальной способности к небывалому.**
Определить, какое небывалое породило событие. Не новое как перекомбинацию известного, а небывалое — форму без аналога.

**Шаг 6. Оценка жизненной силы небывалого.**
Определить, сохранило ли порождённое небывалое способность воспроизводиться и порождать следующее небывалое.

**Шаг 7. Внесение в реестр.**
Внести результат верификации в реестр и карту узлов.

### 10.2. Социальная способность к небывалому

**Социальная способность к небывалому** — способность системы рождать то, чего не было в наличном спектре возможностей. Не новое как перекомбинацию известного, а небывалое — форму, у которой нет аналога.

Это не остаток и не оценка. Это капитал: добрая воля в действии, готовность порождать то, чего ещё нет.

Она отличается от добротности. Добротность измеряет способность резонатора удерживать напряжение **до** события. Социальная способность к небывалому — способность системы порождать новое **после** события. Добротность отвечает на вопрос «сработает ли узел»; способность к небывалому — на вопрос «что родится, когда узел сработал».

| Параметр | Добротность | Социальная способность к небывалому |
|---|---|---|
| Что измеряет | Способность резонатора удерживать колебание | Способность системы порождать небывалое после события |
| Когда применяется | До события (в прогнозе) | После события (в верификации) |
| Что фиксирует | Устойчивость формы при смене содержания | Порождение нового; способность воспроизводиться |
| Носитель | Резонатор | Поле после события |
| Аналог | Коэффициент полезного действия | Способность рождать |

### 10.3. Три состояния небывалого

Социальная способность к небывалому не однородна. Она различается по жизненной силе порождённого.

| Состояние | Что означает | Пример из земельной реформы |
|---|---|---|
| **Мертворождённое** | Возникло в замысле, но не состоялось; способность не удержалась | Надел земли в натуре |
| **Угасающее** | Возникло, но не воспроизводится; способность слабеет | Фермерство, многоукладность |
| **Живое** | Возникло и продолжает воспроизводиться; способность порождает следующее небывалое | Виртуальная доля, кадастр без границ, смена ВРИ без смены категории |

**Живое небывалое** — то, что сохранило способность порождать. Оно не просто осталось — оно продолжает работать. Именно оно определяет, каким станет следующее событие.

### 10.4. Компоненты социальной способности

| Компонент | Что это в методе | Как измерить |
|---|---|---|
| **Доверие** | Мера добротности резонатора без принуждения | Готовность следовать процедуре без контроля |
| **Легитимность** | Способность решения восприниматься как должное | Разница между формальным и реальным сроком исполнения |
| **Социальный капитал** | Сеть связей, удерживающая напряжение после ухода института | Число самоорганизующихся связей |
| **Институциональная память** | Сохранение процедуры при смене носителей | Доля процедур, переживших смену кадров |
| **Неисполненные обещания** | Отрицательная способность: накопленный долг доверия | Число «зависших» актов, сохранивших фазу |

Последний компонент связывает верификацию с археологией: археология работает с **отрицательной способностью** — неисполненными обещаниями, сохранившими фазу. Верификация работает с **положительной способностью** — небывалым, пережившим резонатор.

### 10.5. Метрика социальной способности к небывалому

**Назначение:** оценка способности системы порождать небывалое и удерживать его жизненную силу. Применяется в верификации.

> Способность = (Удерживаемое небывалое − Стоимость формальных ресурсов) / Удерживаемое небывалое

| Значение | Статус | Что означает |
|---|---|---|
| > 0.7 | Живое | Небывалое переживёт резонатор: система порождает и удерживает результат без формальной поддержки |
| 0.3–0.7 | Угасающее | Небывалое держится частично: без поддержки способность деградирует |
| < 0.3 | Мертворождённое | Небывалое исчезнет с уходом резонатора: результат был профинансирован, а не порождён |

**Пример (земельная реформа):**

| Небывалое | Резонатор | Удерживаемое небывалое | Стоимость ресурсов | Способность | Статус |
|---|---|---|---|---|---|
| Виртуальная доля | Суд | 0.8 | 0.2 | 0.75 | Живое |
| Кадастр без границ | Росреестр | 0.7 | 0.3 | 0.57 | Угасающее |
| Надел в натуре | Госкомзем | 0.05 | 0.9 | 0.05 | Мертворождённое |

Виртуальная доля удержалась: суд сохранил добротность после события, и способность пережила формальную поддержку. Надел в натуре не удержался: способность держалась на ресурсе, которого не было.

### 10.6. Критерий верификации

Сценарий считается верифицированным, если:

1. зафиксированные узлы совпали с фактическими событиями;
2. резонатор идентифицирован верно;
3. условие-триггер сработало;
4. определена социальная способность к небывалому — живая, угасающая или мертворождённая;
5. определена жизненная сила порождённого небывалого.

Если сценарий не верифицирован — зафиксировать расхождение и внести его в реестр как новую траекторию.

### 10.7. Принцип способности

**Событие сработало — но что стало способно случиться?**

Это вопрос, который верификация задаёт после каждого узла. Без него метод фиксирует срабатывание, но не фиксирует порождение. Без него нельзя ответить, была ли система устроена так, чтобы удерживать результат, — или только так, чтобы его произвести.

> *Резонатор превращает возможность в действительность. Социальная способность к небывалому показывает, что из этой действительности переживёт своего творца и продолжит рождать.*

### 10.8. Жизненная сила небывалого

Верификация различает три состояния небывалого:

1. **Мертворождённое** — возникло в замысле, но не состоялось. Пример: надел в натуре.
2. **Угасающее** — возникло, но не воспроизводится. Пример: фермерство, многоукладность.
3. **Живое** — возникло и продолжает воспроизводиться, порождая следующее небывалое. Пример: виртуальная доля, кадастр без границ, смена ВРИ без смены категории.

**Живое небывалое** — то, что сохранило способность порождать. Именно оно определяет, каким станет следующее событие.

# ЧАСТЬ III. ИНСТРУМЕНТЫ

Инструменты — фиксация результатов цикла. Три инструмента: метрики, реестр, карта. Каждый применяется в определённом шаге цикла и не существует отдельно от него.

## 11. Четыре метрики

### 11.1. Метрика напряжённости

**Назначение:** оценка разности потенциалов. Применяется в наложении для присвоения статуса узла.

Напряжённость = |Форма − Функция| + |Обещание − Возможность| + |Язык − Произнесение| + |Резонатор − Траектория|

| Компонент | Что измеряет | Источник |
|---|---|---|
| Форма − Функция | Разрыв между правом и экономикой | Правовые базы + статистика |
| Обещание − Возможность | Разрыв между обязательством и ресурсом | Акты + бюджет |
| Язык − Произнесение | Разрыв между языком и напряжением | Словари + новые явления |
| Резонатор − Траектория | Рассогласование частот | Реестр + ряд |

| Уровень | Значение | Статус узла |
|---|---|---|
| Низкий | 0–1.0 | Фоновый шум |
| Средний | 1.0–2.0 | Приближение волны |
| Высокий | 2.0–3.0 | Близкая детонация |
| Критический | 3.0–4.0 | Событие неизбежно |

**Пример:** узел 1998 года — напряжённость 2.5 (критический).

### 11.2. Метрика резонанса

**Назначение:** оценка близости частот резонатора и траектории. Применяется в наложении.

Резонанс = |Частота резонатора − Частота траектории|

| Значение | Статус узла |
|---|---|
| < 0.1 | Событийный |
| 0.1–0.3 | Критический |
| > 0.3 | Фоновый |

### 11.3. Метрика добротности

**Назначение:** оценка способности резонатора удерживать колебание. Применяется в прогнозе.

Добротность = (Число сохранённых процедур) / (Общее число процедур)

| Значение | Статус резонатора |
|---|---|
| > 0.7 | Устойчивый |
| 0.3–0.7 | Переменный |
| < 0.3 | Теряющий |

### 11.4. Метрика реализуемости

**Назначение:** определение того, какая возможность реализуется. Применяется в прогнозе.

Реализуемость = Резонанс × Добротность

| Значение | Статус |
|---|---|
| > 0.7 | Возможность реализуется |
| 0.3–0.7 | Возможность вероятна |
| < 0.3 | Возможность не реализуется |

**Пример (узел 1998 года):**

| Возможность | Резонатор | Резонанс | Добротность | Реализуемость |
|---|---|---|---|---|
| Дефолт и передел | Суд | 0.9 | 0.9 | 0.81 |
| Монетизация | Центробанк | 0.8 | 0.6 | 0.48 |
| Обвал | — | — | 0.2 | 0.20 |

Реализуется дефолт и передел.

## 12. Реестр

**Назначение:** единое поле для траекторий и резонаторов. Применяется в обнаружении и наложении.

### 12.1. Формат записи

| Объект | Тип | Природа / Тип резонатора | Частота | Амплитуда / Добротность | Фаза / Полоса | Статус |
|---|---|---|---|---|---|---|
| Бюджетный цикл | Траектория | Экономическая | Годовая | Высокая | В фазе | Активна |
| Кадровая ротация | Траектория | Антропологическая | 2–4 года | Средняя | Привязка к инвентаризации | Активна |
| Судебные иски | Траектория | Правовая | Волновая | Высокая | Сдвиг при банкротствах | Активна |
| Демографический цикл | Траектория | Биосоциальная | 25–30 лет | Высокая | Наложение на переписи | Активна |
| Неисполненные обещания | Траектория | Политико-правовая | 5–10 лет | Средняя | Детонация на поколениях | Активна |
| Суд | Резонатор | Институт | Процессуальная | Высокая | Узкая | Активен |
| Кадастр | Резонатор | Институт | 5–7 лет | Средняя | Узкая | Активен |
| Монархия | Резонатор | Активный | Широкополосная | Переменная | Широкая | Спящий |
| Ваучер | Резонатор | Фиктивный объект | Волновая | Низкая | Широкая | Спящий |
| Центробанк | Резонатор | Институт | Кредитная | Высокая | Узкая | Активен |

### 12.2. Критерии внесения

**Траектория** вносится, если:

1. ряд устойчив на горизонте ≥ 5 лет;
2. параметры (амплитуда, частота, фаза) измеримы;
3. не сводится к другой траектории.

**Резонатор** вносится, если:

1. имеет собственную частоту;
2. обладает добротностью;
3. может быть рассогласован сам с собой;
4. не сводится к траектории.

### 12.3. Принципы

**Открытость:** реестр дополняется по мере обнаружения новых объектов.

**Совместимость:** единый формат, измеримые параметры, указанный горизонт.

## 13. Карта узлов

**Назначение:** фиксация узлов на временной оси. Применяется в наложении, археологии, верификации.

### 13.1. Формат записи узла

t → (A₁, A₂, Δφ, R, статус)


где:

- `t` — время узла;
- `A₁`, `A₂` — траектории;
- `Δφ` — сдвиг фаз;
- `R` — резонатор;
- статус — фоновый, событийный, критический.

### 13.2. Пример карты

1991 → (инерция, шоковая экономика, Δφ=0.2, Государство, событийный)
1993 → (обещания, демография, Δφ=0.0, Конституция, критический)
1998 → (заимствования, нормы, Δφ=0.0, Суд, критический)
2008 → (цены, кадры, Δφ=0.1, Корпорации, событийный)
2014 → (заимствования, нормы, Δφ=0.2, Центробанк, событийный)
2020 → (демография, кадры, Δφ=0.3, Государство, фоновый)

### 13.3. Табличная форма

| Узел | Траектория 1 | Траектория 2 | Δφ | Резонатор | Статус | Что проявляется |
|---|---|---|---|---|---|---|
| 1991 | Инерция | Шоковая экономика | 0.2 | Государство | Событийный | Начало реформы |
| 1993 | Обещания | Демография | 0.0 | Конституция | Критический | Детонация |
| 1998 | Заимствования | Нормы | 0.0 | Суд | Критический | Передел |
| 2008 | Цены | Кадры | 0.1 | Корпорации | Событийный | Консолидация |
| 2014 | Заимствования | Нормы | 0.2 | Центробанк | Событийный | Новый передел |
| 2020 | Демография | Кадры | 0.3 | Государство | Фоновый | Подготовка |

### 13.4. Применение

Карта позволяет видеть:

- «созвездия» узлов, а не отдельные события;
- через какой резонатор проходит каждое событие;
- где накапливается напряжённость;
- какое небывалое породило каждое событие и сохранило ли оно жизненную силу.

Созвездие узлов — индикатор приближения волны.

# Резолюция

### Формула метода

> **Поле напряжений → траектории → резонаторы → узлы → сценарии → верификация → социальная способность к небывалому.**

### Принцип работы

Метод не заменяет манифест. Он его применяет. Если манифест — это онтология, то метод — это операциональная надстройка. Инструменты оснащают метод, но не заменяют его.

### Принцип расширения

Каждый новый полигон проверяется по трём метрикам:

1. доля узлов, зафиксированных методом до события — порог ≥ 60%;
2. доля узлов с верно идентифицированным резонатором — порог ≥ 50%;
3. доля небывалого, сохранившего жизненную силу — порог ≥ 30%.

### Принцип остановки

Если добавление новой траектории или нового резонатора не меняет узлы — остановиться. Метод не стремится к бесконечному расширению. Он стремится к фиксации чертежа.

### Итоговая резолюция

Метод не даёт окончательного ответа на вопрос «почему?». Он даёт инструмент, чтобы увидеть *как*: как система устроена в своей многослойной, нелинейной, нередуцируемой сложности. И — *что*: что из случившегося стало способно жить и порождать небывалое.

> *Интерференция — это не окно в сущность. Это способ читать отношение как реальность. Социальная способность к небывалому — часть этой реальности.*
